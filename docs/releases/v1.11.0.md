## 新增

- 新增应用内版本检测与非打扰提示：
  - 主进程启动后后台静默检查最新版本（自动跳过 `--worker` 工作进程），支持在底部状态栏展示紧凑更新条、在左下角设置按钮展示提醒圆点，并在设置菜单与关于弹窗提供一键检查入口。
  - 支持“稍后提醒”（当前会话关闭横幅）与“忽略此版本”持久化记忆，不弹窗打断日常调试工作流。
- 新增跨平台在线更新（下载、校验与安装引导）：
  - 应用内流式下载当前系统对应的安装包，实时展示下载进度、文件体积并支持随时取消；关闭更新窗口后仍可在后台继续下载并通过底部状态栏跟进。
  - 下载过程实时计算并比对 SHA-256 摘要，校验失败自动清理残余临时文件，防止损坏包被执行。
  - 平台差异化一键安装：Windows 启动 Inno Setup 安装向导并安全退出当前进程（若正在执行 MQTT 模拟，会先二次确认并优雅停止所有模拟分片进程）；macOS 自动挂载打开 `.dmg` 安装镜像；Linux 自动定位并打开归档包目录；同时保留跳转浏览器发布页下载兜底。
- 新增更新源加速与自定义清单支持：
  - 优先拉取无 API 频控限制的 `latest.json` 静态更新清单，并兼容回退 GitHub Releases API。
  - 支持配置 GitHub 下载加速镜像前缀（如 `https://ghfast.top`）或自定义 `latest.json` 托管地址，兼顾国内与受限网络环境。
- 升级发布流水线（`release.yml`）：
  - 新增独立的聚合发布阶段，自动汇总 Windows / macOS / Linux 三端产物并生成 `latest.json` 在线更新清单与 `SHA256SUMS.txt` 校验文件，消除多平台并发上传 Release 的竞态风险。

## 优化

- 增强版本号解析与语义化比对（`VersionHelper`）：自动剥离构建日期后缀（`-YYYYMMDD`）与构建号（`+N`），避免正式打包版本被标准 SemVer 误判为低于同版本 Tag 的预发布版而重复提示更新。
- 统一“关于”窗口版本号标签国际化文案，并集成快捷检查更新操作。
